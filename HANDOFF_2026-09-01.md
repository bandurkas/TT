## Spec: manual ad-Cost entry + cost lots UI (given to the frontend agent 2026-09-01, for reference/resume)

**A) Manual daily ad Cost** — in zone 1 next to `AdvertisingSource`, a compact form "Enter today's ad Cost from Ads Manager" / RU «Внести расход на рекламу из Ads Manager»: date (default today, shop tz), Cost (IDR), SKU orders, Gross revenue, checkbox "Day complete (final figures)" / «День закрыт (итоговые цифры)», optional note, Apply/«Применить» button.
`POST /api/advertising/manual` `{date, cost: string, sku_orders, gross_revenue: string, final: bool, note}` → 201 `{report_id, partial, recomputed:{orders, inserted}, day:{date,cost,source,partial,...}}`; 422 with `detail` string (newer entry exists / future date / final on unfinished day) shown inline. On success refetch overview/trends/insights/funnel/video-products.
Also render a per-day table from `GET /api/advertising?from&to` (`days[].source` = `"shop_overview"|"manual_entry"`, `days[].observed_at`, `days[].note`, `manual_days`, `source` label, `entry_note`): Date · Cost · SKU orders · Gross revenue · Source chip ("Campaign overview export"/"Manual entry" · RU «выгрузка»/«ручной ввод») · Partial flag · observed time. Keep honesty labels: manual = operator-transcribed, replaced only by a newer observation, superseded automatically once Ads API connects.

**B) Product cost (COGS) with a lock** — in zone 1 unit-economics card, a "Product cost" panel from `GET /api/costs?from&to` → `{default_cogs_per_unit, lots[], skus[], note}`. `lots[]`: `{id, scope "all"|"product"|"sku", product_id, sku_id, received_on, unit_cost, quantity|null, currency, note, active, consumed?, remaining?, shared_skus?}`. `skus[]`: `{sku_id, external_sku_id, product_id, product_title, sku_title, current_cost, source "lot"|"seed"|"default"|"none", lot_id, effective_from, history[]}`.
UX per client's explicit ask: checkbox "Locked" (checked by default, fields read-only) → uncheck to edit → (1) default cost per unit → `POST /api/costs/default {default_cogs_per_unit}`; (2) lots list: add (scope + product/sku picker from `skus[]`, received_on, unit_cost, quantity optional, note) → `POST /api/costs/lots` (201 `{lot_id, versions, skus_with_lots, recomputed}`); edit/deactivate → `PATCH /api/costs/lots/{id} {received_on?, unit_cost?, quantity?(0=clear), note?, active?}`. On success: "Applied — N orders recomputed", auto re-lock, refetch overview/products/funnel/video-products. Explain FIFO from the API `note` (a shared-scope lot's quantity is consumed once across ALL its SKUs' combined sales — `shared_skus` shows how many; a lot without quantity applies until the next one; a lot's seed price still covers time before its first lot). Status chips: "queued" (no consumed/remaining), "active" (current source), "sold out" (remaining=0). Per-SKU table with expandable history. RU strings throughout. Fixtures `advertising.json`/`costs.json` were being added (see uncommitted files above — verify their numbers match the shapes here, they may already be usable).
