## 4. Как проверять (скрипты в `scripts/ops/tt/`, запуск с Mac)
```
scp -q scripts/ops/tt/<x>.py vps3:/tmp/<x>.py
ssh vps3 "cd /root/TT && docker compose exec -T worker python -c \"from apps.worker import main; main.run('ads_tiktok')\" >/dev/null 2>&1; docker compose exec -T worker python -I - < /tmp/<x>.py" | grep -v 'retry in'
```
- `verify.py` — цены, активные акции/купоны, затрагивающие чёрные; `stock2.py` — остатки чёрных; `camp_status.py` — список GMV Max кампаний (status, modify_time UTC); `creatives_today.py` — расход по роликам Black one за дату (правь даты в файле); `promo_read.py` — все активные акции и купоны; `new_objs.py`/`kill_smart.py` — разбор автоматики; `restore2.py` — вернуть товары в наши скидки (используется после авто-flash); `three.py` — шаблон смены % скидки (PUT …/activities/{id}/products с `activity_id` в теле); `edit8.py` — частичная правка карточки (partial_edit title/description); `stock.py` — остатки по SKU (inventory/update).
- SQL для прибыли по дням: `analytics_shop_daily` (net_profit, ad_cost_partial), по товару `analytics_product_daily` (product_id 662 = набор, 3/4 = SKU чёрных); цены в заказах — из `raw_api_responses` (resource ilike '%order%', line_items.sale_price, order_type).
- Себестоимость: `POST localhost:8400/api/costs/lots` на VPS (без auth изнутри), `GET /api/costs`.

## 5. Проверенные вызовы Shop API (не угадывать другие)
- Акции: `POST /promotion/202309/activities/search` (page_size числом в теле), `GET /promotion/202309/activities/{id}`, `POST /promotion/202309/activities` (DIRECT_DISCOUNT, product_level PRODUCT), `PUT /promotion/202309/activities/{id}/products` (тело: activity_id + products[{id, discount, quantity_limit −1, quantity_per_user −1}]), `POST …/activities/{id}/deactivate`.
- Купоны: `POST /promotion/202406/coupons/search`, `GET /promotion/202406/coupons/{id}`; **деактивация купона через API не найдена** (`…/coupons/{id}/deactivate` → Invalid path).
- Товар: `get_product`, `POST /product/202309/products/{id}/prices/update`, `POST /product/202309/products/{id}/inventory/update`, `POST /product/202309/products/{id}/partial_edit` (title/description; живой текст после авто-проверки ~2 мин).
- **Нельзя через API:** Smart promotion plan и авто-flash (`Permission Denied`), реклама (бюджет/ROI/креативы), регистрация на акции платформы.
