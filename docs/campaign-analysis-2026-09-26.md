# Почему после перезапуска кампании стало плохо. 2026-09-26

Источник: прод TT (`ad_metrics` по кампаниям и товарам из Ads API, `analytics_shop_daily`,
`order_items`), 20.08–25.09. Себестоимость 2 500/пара. Все суммы в рупиях.
«Перезапуск» = 12.09 выключено всё (расход 21 за день, 0 заказов) → 13.09 восемь Smart_Growth →
14.09 «majority black» удалена, создана «black one» на тот же товар, плюс «mix product»,
«abu abu product», 15.09 «LIVE GMV Max_Gross Gacoooor!».

## Итог одной строкой

13–25.09 магазин потерял **−2 504 689** при рекламе 6 883 956 и 133 заказах (CPO 51,7k при
безубыточном ~32k). Из этого **3 884 485 (56 % расхода) ушло на кампании без истории** — 54 заказа,
CPO 72k: `mix product` 1,40m / 8, LIVE 691k / 9, Smart_Growth 284k / 2, Unisex-авто 345k / 7.
Сама «black one» 14–25.09: 2,999m / 80 заказов, CPO 37,5k, ROI 1,60 — около нуля, с провалом 23–25.09.

## Чего в данных нет

Целевой ROI, ставки, аудитории, креативы кампаний — отчёт GMV Max их не отдаёт. Показы и клики по
карточкам в `product_metrics` = 0 (API не отдаёт), поэтому разложить провал 23–25.09 на CTR/CVR нельзя.
Внутридневной истории нет (сырые снимки хранят только число строк).

## Что делать (в порядке денег)

1. **Бюджет «black one» назад к 130–150k/день.** CPO 21–30k измерен дважды только в этом режиме
   (A и D). Не менять бюджет больше чем на 20 % в день, кампанию не пересоздавать.
2. **Выключить** Unisex-авто `…3432193` (345k / 7, ROI 0.95) и LIVE Gacoooor (691k / 9, CPO 77k;
   LIVE GMV Max магазину по-прежнему недоступен). `mix product` уже удалена 22.09.
3. **abu abu** держать ≤ 60–100k/день: CPO 38k при безубыточном ~35k — в нуле, не масштабировать.
4. **Цена** — главный рычаг, решение владельца. При 50k запас 32k на заказ, при 80k был 65k.
   Срез цены объёма не дал. Прайс-цену не дёргать (пять значений за неделю).
5. Новые карточки (Two Tone, Putih, органайзеры) — без органических продаж не рекламировать: в GMV Max
   деньги идут туда, где нет заказов (Two Tone 1,4m / 8).

Проверка через 3 дня: CPO «black one» ≤ 32k на бюджете 130–150k; дневной расход магазина ≤ 250k;
прибыль по `analytics_shop_daily` ≥ 0.
