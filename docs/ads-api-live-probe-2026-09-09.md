## Карта эндпоинтов

- `/gmv_max/campaign/get/` — требует `filtering.gmv_max_promotion_types`; допустимые значения
  **`LIVE_GMV_MAX`, `PRODUCT_GMV_MAX`** (получено из текста ошибки API)
- `/gmv_max/report/get/` — требует `store_ids`
- `/store/list/` — ключ ответа **`stores`**, не `list`
- `/report/integrated/get/` — обычные кампании; у этого магазина расход по ним нулевой

**Метрики.** Валидны: `cost`, `net_cost`, `orders`, `gross_revenue`, `roi`.
Невалидны: `spend`, `impressions`, `clicks` — их в GMV Max отчёте нет.

**Разрезы.** Имена не угадываются, взяты из документации Supermetrics (портал TikTok рендерится JS
и прямым фетчем отдаёт только заголовок):

| dimension | смысл | условие |
|---|---|---|
| `campaign_id` | кампания | работает сам по себе |
| `stat_time_day` | день | только вместе с 1–3 «main» разрезами |
| `item_group_id` | товарная группа | нужен `filtering.campaign_ids` |
| `item_id` | **креатив = ID видео** | нужны `filtering.campaign_ids` **и** `item_group_ids` |

Отвергнуты: `product_id`, `creative_id`, `video_id`, `material_id`, `ad_id`, `sku_id`, `adgroup_id`,
`store_id`, `campaign_name`, `gmv_max_campaign_type` — все дают бесполезное `ERROR Message.`

`enable_total_metrics: true` добавляет блок `total_metrics` — удобно для сверки сумм.

## ❌ Разрез по креативу: структурно есть, практически пуст. §5.15 так не решается

Цепочка: `campaign_id` → `item_group_id` (фильтр по кампании) → `item_id` (фильтры по кампании и группе).
`item_id` — 19-значный ID видео. Отдельное значение **`-1` = неатрибутированная корзина**.

Измерено на **трёх активных кампаниях** основного кабинета, 01–08.09 (закрытые дни):

| кампания | cost всего | по видео | orders всего | по видео |
|---|---|---|---|---|
| 1872852148459778 | 1 603 945 | 238 902 (15%) | 42 | 2 |
| 1874692964779154 | 354 549 | 37 339 (11%) | 6 | 0 |
| 1875228349709633 | 46 135 | 26 898 (58%) | 3 | 0 |
| **итого** | **2 004 629** | **303 139 (15%)** | **51** | **2** |

Выручка: 3 443 948 всего, по видео — 125 901 (**3,7%**).

**96% заказов и выручки падают в `-1`.** За неделю по всем кампаниям нашлось ровно два видео
с атрибутированным заказом:

```
7679305068755176725  cost=87444  orders=1  rev=70604
7680775757052005653  cost=62183  orders=1  rev=55297
```

Два наблюдения против 49 неатрибутированных заказов — это не основание масштабировать креатив.
На старой кампании `1871407217911441` картина та же (91% в `-1`), то есть дело не в конкретной
кампании, а в природе GMV Max: TikTok собирает выдачу сам и по-креативно конверсии не раскрывает.

**Вывод: пока расход идёт через GMV Max, ROI на видео не считается.** Ни через свой API, ни тем
более через сторонние коннекторы (у Windsor `creative_id`/`video_id` вообще null). Задача §5.15
`creative_mappings` этим путём закрыта быть не может — нужно менять постановку, а не источник.

Что остаётся для покреативной аналитики: Shop Data Insights `shop_videos/performance` даёт заказы
и выручку **по видео со стороны магазина**. Это не даст разложить рекламный расход по видео,
то есть per-video ROI всё равно не получится, но связка «органика по видео + расход по кампании»
доступна. Решение по постановке — за владельцем.
